# Personal Comfort Device (PCD) Wrist Rest
This repo contains the 3d file for the skeletal shell of a keyboard wrist rest with heating and cooling capabilities.  
Heating via HTS/Amptek Standard Insulated Tape and mylar lined up along the U-shaped troughs.  
Cooling via two simple 5v blower fans housed on each side.  
Heating and cooling capabilites controlled by PCD Hub - area for Hub extension housed in the middle, in between the troughs.  
Add plastic mesh into side grooves and under outer shell for comfortable surface to plant wrists.
